# 🚀 Rvan-Api

Simple REST API for WhatsApp Bot

## 📌 Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/quote` | GET | Random quote |
| `/api/cuaca` | GET | Weather info |
| `/api/gempa` | GET | Latest earthquake |
| `/api/doa` | GET | Random prayer |
| `/api/translate` | GET | Translate text |
| `/api/qrcode` | GET | Generate QR code |
| `/api/stiker` | GET | Make sticker |
| `/api/ping` | GET | Check status |

## 🚀 Usage

```bash
npm install
node api.js
